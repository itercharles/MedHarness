# Interface issues: names, definitions and functions that are ambiguous, inconsistent or unused

Task T6a of [the positioning-gaps plan](2026-11-19-positioning-gaps-plan.md). A list only: nothing here has been changed. The project has no real users, so compatibility does not count; the owner decides change / keep per item.

How it was checked: each command was run with `.venv/bin/medharness` in a scratch project (`medharness init`, one git commit), and every `--help`, `docs/interface.md` and `medharness/results.py` were read. "No reader" means a grep of `medharness/`, `scripts/` and `tests/` found nothing that consumes the field. Items are ranked by how confusing they are to a first-time user, most confusing first. **Decision** is left blank for the owner.

Not verified (could not run here): the JSON of `build plan` / `build code` (needs a model), a successful `build release`, `build validation`, and `verify soup` against a live osv.dev. Items about those are read from code and `--help` only and say so.

## Notes

- **Confusion ranking.** Items 1 to 5 are what a first-time user meets in the first hour (a command that sometimes writes, a flag that means two things, results that say "ok" four ways, an option named for something it is not). 6 and 7 are not naming problems but silent acceptance of input the tool then ignores or stores wrongly; they are listed here because the decision (what may a caller set) is an interface decision. 17 to 20 only matter to someone reading the reports closely, and to the owner's rule against fields nothing uses.
- **Not inconsistent, kept off the list:** `item list` writes one JSON object per line while everything else writes one object; the doc states it. Exit-1-with-empty-stdout for unreadable DHF or unknown item; the doc states it. `--doc-format` is the same on all three commands that take it.
- **Related plan items.** Items 1 to 5, 8, 16 to 19 are the breaking changes T6d would otherwise freeze. `RunWarning.details` and the diagnostics fields (17, 18) were named in the plan; both are confirmed.
