# {{project_name}}-dhf

Design History File for **{{project_name}}**, maintained under {{standards}}.

This repository serves two purposes:

1. **Regulatory documentation** — {{project_name}}'s own DHF, maintained under the
   applicable medical device software standards.
2. **Design history template** — generated by CompliantFlow and ready to customize
   for your project.

## Structure

```
DHF/          # Design History File (items, config, documents, test-results)
governance/   # Compliance policy files (IEC_62304.yaml, ISO_14971.yaml, ...)
```

## Usage with CompliantFlow

```bash
# Install CompliantFlow
git clone https://github.com/compliantflow/compliantflow
cd CompliantFlow
pip install -e .

# Clone this DHF alongside
git clone https://github.com/{{github_org}}/{{dhf_repo_name}}

# Run compliance checks
compliantflow --dhf {{dhf_repo_name}}/DHF validate compliance IEC_62304 \
  --governance-dir {{dhf_repo_name}}/governance
```

## DHF utilities

The `dhf_util/` package is the DHF system's own API (item CRUD, lifecycle transitions,
schema validation). It is a dependency of CompliantFlow and ships with the
CompliantFlow-DHF repository.

```bash
# Create a new item
python -m dhf_util --dhf DHF item create --type SRS --title "My requirement"

# Run DHF utility tests
pytest dhf_util/tests/ -v
```
